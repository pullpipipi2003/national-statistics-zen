Built for the [Make the best national statistics site](https://make.fun/bounty/best-national-statistics-site-20261126-0539) bounty on [make.fun](https://make.fun).

Offline-first national statistics portal presenting macroeconomic, trade, demographic, labour, and provincial socio-economic indicators for Vietnam (2015–2025).

## Run Locally

```bash
node serve.ts --port 8080
```

## Build Submission Output

```bash
MAKEFUN_OUTPUT_DIR=out node main.ts
```
